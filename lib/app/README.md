# Carpeta app

Aqui vive la configuracion global de la aplicacion.

## Que va aqui
- Punto de entrada de la aplicacion (`app.dart`).
- Tema global (`theme/`).
- Ruteo global (opcional: `router/`).

## Estructura de nombres
- Archivos: `snake_case.dart`.
- Clases principales: `App`, `AppTheme`, `AppRouter`.

## Tipos de archivo
- `.dart` para codigo.
- `.md` para documentacion interna.
