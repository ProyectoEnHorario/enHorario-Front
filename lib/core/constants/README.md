# Carpeta core/constants

Define constantes estaticas y centralizadas.

## Que va aqui
- Textos de UI.
- Keys de almacenamiento.
- Endpoints o nombres de colecciones (si aplica).

## Estructura de nombres
- Archivo sugerido por dominio: `app_strings.dart`, `api_constants.dart`.
- Constantes en clases con `static const`.

## Tipos de archivo
- `.dart`.
