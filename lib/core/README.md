# Carpeta core

Incluye elementos compartidos por multiples features.

## Que va aqui
- Constantes de texto, claves, valores comunes.
- Utilidades puras.
- Widgets reutilizables.

## Estructura de nombres
- Subcarpetas por responsabilidad: `constants`, `utils`, `widgets`.
- Archivos: `snake_case.dart`.

## Tipos de archivo
- `.dart` y `.md`.
