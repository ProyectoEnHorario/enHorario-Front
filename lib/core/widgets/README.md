# Carpeta core/widgets

Widgets compartidos que no pertenecen a una sola feature.

## Que va aqui
- Tarjetas base.
- Inputs compartidos.
- Componentes de carga/error reutilizables.

## Estructura de nombres
- Archivos por widget: `section_card.dart`, `app_button.dart`.
- Clase y nombre de archivo alineados por responsabilidad.

## Tipos de archivo
- `.dart`.
