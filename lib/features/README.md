# Carpeta features

Agrupa la aplicacion por funcionalidades de negocio.

## Que va aqui
- Cada feature en su propia carpeta (`home`, `auth`, `reports`, etc).
- Cada feature puede usar capas `data`, `domain`, `presentation`.

## Estructura de nombres
- Carpeta feature en `snake_case`.
- Mantener independencia entre features.

## Tipos de archivo
- `.dart` y `.md`.
