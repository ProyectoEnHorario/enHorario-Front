# Feature home

Modulo ejemplo de inicio para mostrar tiempos de espera.

## Que va aqui
- `data/`: fuentes e implementaciones.
- `domain/`: entidades y contratos.
- `presentation/`: UI y widgets de pantalla.

## Estructura de nombres
- Archivos en `snake_case.dart`.
- Separar responsabilidades por capa.

## Tipos de archivo
- `.dart` y `.md`.
