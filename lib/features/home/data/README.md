# Carpeta home/data

Capa de acceso y transformacion de datos.

## Que va aqui
- Models.
- Repositorios concretos.
- Adaptadores de API o base de datos.

## Estructura de nombres
- Modelos: `*_model.dart`.
- Repositorios concretos: `*_repository.dart` o `in_memory_*_repository.dart`.

## Tipos de archivo
- `.dart`.
